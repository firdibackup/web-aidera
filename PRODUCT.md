# Product

## Register

product

## Platform

web

## Users

Pemilik dan operator AIDERA yang mengelola strategi, produksi, approval, jadwal, dan audit konten dari laptop lokal. Pengguna bekerja dalam alur operasional harian dan perlu melihat keputusan, blocker, serta pekerjaan agent tanpa kehilangan konteks.

## Product Purpose

AIDERA Content Studio adalah control center produksi konten untuk menghubungi tujuh agent spesialis, menyusun dan menyetujui rencana, memindahkan konten melalui pipeline, mengatur kalender editorial, meninjau artifact terversi, dan menjaga seluruh keputusan tetap dapat diaudit. Keberhasilan berarti pekerjaan nyata dari Bridge dapat dipahami dan dikendalikan dengan cepat, sementara state penting tetap persisten setelah refresh.

## Positioning

Satu workspace manual-first yang menyatukan perencanaan, specialist-agent chat, produksi, penjadwalan, artifact, dan human approval tanpa menyerahkan kontrol strategis kepada automation.

## Brand Personality

Premium editorial, hangat, tegas, fokus, dan dapat dipercaya. Bahasa antarmuka ringkas dan operasional; aktivitas agent harus terasa nyata, bukan teatrikal.

## Anti-references

Jangan menyerupai dashboard SaaS generik, template admin mentah, e-commerce dashboard, office simulation, atau antarmuka agent yang mengarang status kerja. Hindari glassmorphism dekoratif, chart dummy, avatar stok, gradien neon, dan card grid monoton.

## Design Principles

1. Keputusan manusia selalu terlihat dan tidak pernah dilewati diam-diam.
2. Tampilkan state operasional nyata; ketidaktersediaan data lebih baik daripada data palsu.
3. Strukturkan output kompleks menjadi objek yang dapat ditinjau dan ditindaklanjuti.
4. Buat pipeline mudah dipindai tanpa menyembunyikan provenance, versi, atau blocker.
5. Adaptasikan layout terhadap konteks perangkat tanpa menghilangkan fungsi inti.

## Accessibility & Inclusion

Target minimum WCAG 2.2 AA. Semua fungsi inti harus dapat digunakan dengan keyboard, fokus harus terlihat, target sentuh minimal 44×44 px pada perangkat sentuh, status tidak boleh bergantung pada warna saja, dan motion harus menghormati `prefers-reduced-motion`.
